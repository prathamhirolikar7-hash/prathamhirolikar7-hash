### Projects

**[BrightBasket: Where is the profit going?](https://github.com/prathamhirolikar7-hash/brightbasket-margin-leak)**
Excel, SQL, Python

An online brand grew its orders by 30% in a year, but profit did not grow. I found that 28% of orders were losing money, which added up to ₹11.5 lakh a year. Most of the loss came from Cash on Delivery orders in small cities. Stopping COD everywhere would have hurt profit in big cities, so I suggested two smaller changes that save about ₹5.7 lakh a year.

**[Swiggy: Best city for a new cloud kitchen](https://github.com/prathamhirolikar7-hash/swiggy-cloud-kitchen)**
PostgreSQL, Excel

I cleaned and analysed 1.48 lakh Swiggy restaurant listings to rank 33 smaller cities for a new cloud kitchen. I also noticed that many listings are the same kitchen under different brand names. One kitchen in Bengaluru had 194 brands. So I counted real kitchens instead of listings. Top pick: Vizag.
